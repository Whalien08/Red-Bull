# RedBull F1 Showcase 🏎️

An interactive, single-page website dedicated to the Oracle Red Bull Racing Formula One team. This project showcases the team's history and features a custom-built interactive slider to browse their iconic F1 car models.

> **Note:** This project is currently in active development.
**Live Demo:** [View Deployed Project Here](https://whalien08.github.io/Red-Bull/)

## ✨ Current Features
* **Custom JS Carousel:** A fully functional, interactive slider built with Vanilla JavaScript to browse through RedBull F1 car models (from RB01 to RB22).
* **Dynamic Navigation:** A responsive navigation bar that starts as a vertical sidebar on the home screen and seamlessly transforms into a fixed top-bar as the user scrolls.
* **Smooth Scrolling:** Implemented CSS scroll-behavior for elegant navigation between page sections.
* **Separation of Concerns:** Clean project structure with separated HTML, CSS, and JS files.

## 🛠️ Technologies Used
* **HTML5** (Semantic structure)
* **CSS3** (Custom styling, flexbox layouts, scroll-snapping, and transition animations)
* **Vanilla JavaScript** (DOM manipulation and event listeners)

## 🚀 How to Run Locally
No installation or build steps are required. 
1. Clone this repository or download the files.
2. Open `index.html` in your favorite web browser.
